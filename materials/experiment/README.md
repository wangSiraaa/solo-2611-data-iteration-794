# 节能试验材料（成对电量差 + 实际随机方案复核）

一小时等长基准/观察的合成场景：两对的（左基准、左观察；右基准、右观察）
功率分别为 (6、2；2、2) 与 (4、2；2、2)，观察时两对均左侧受干预。

* EXP1：两对各自独立抽签（签组 g1、g2）。观察统计量 6，单侧概率 1/4。
* EXP2：两对共用同一签、同向接线（签组 g）。同一观察统计量 6，单侧概率 1/2。
* 更正：把第一对左站 A 的观察功率由 2 更正为 6（轨迹 A 从 a1 修到 a2），
  重算得 A#r2（站点差 0）；在 EXP1 上发布 R3：统计量 2，概率 1/2。
  已发布的 R1 仍指回 A#r1，`verify_report` 可从绑定版本重算核对。

附带演示（不作为试验输入，仅站点结果）：

* E：不等长基准 [0,1) 功率 8 与 [1,3) 功率 2，观察 [3,4) 功率 2。
  基准平均功率按合计电量/合计时长 = 12/3 = 4（不是各段平均的均值 5），
  站点差 4×1 − 2 = 2。
* F0：观察时段功率为 0 —— 这是测量值，站点差 4×1 − 0 = 4。
* F1：观察时段没有测段 —— 缺证，报告缺口 [1,2)，不是 0。
* H：换表示例。基准 [0,1)、观察 [1,2)，旧表恒 2、新表恒 1，切点只
  知道在 [0,2]。切点 0 或 2 都得差 0，切点 1 得 1 —— 不唯一，
  给出两个导致不同结果的切点 (0→0 与 1→1)，不采用。
